## Context

네이버 지도 위에서 경로를 클릭으로 그리고, 여러 경로를 색상별로 관리하고, GPX 파일로 내보내기/가져오기하는 클라이언트 전용 웹 도구. 기존 GPX 에디터(gpx.studio 등)가 전부 OSM 기반이라 한국 지도가 약한 빈 자리를 노림.

## 기술 스택 (확정)

- **프레임워크:** Next.js (App Router), `output: 'export'` 정적 빌드
- **스타일링:** Tailwind CSS (다크 테마)
- **지도:** 네이버 지도 API v3 (NCP), `next/script` 로딩
- **GPX:** 브라우저 DOMParser (파싱) + 수동 XML 생성 (내보내기)
- **상태:** React Context + useReducer
- **테스트:** Vitest
- **배포:** Vercel 정적 배포 (main 푸시 → 자동 배포)

## 아키텍처 결정사항 (eng review에서 확정)

1. **`naverMap.ts` 제거** → 순수 수학(Haversine)만 `lib/geo.ts`로 분리, 폴리라인/마커 조작은 `NaverMap.tsx` 내부
2. **지도 로딩 상태** → NaverMap.tsx에 loading/ready/error 3가지 상태 관리. 에러 시 사용자 메시지, 로딩 시 스피너
3. **localStorage 방어** → 저장/복원을 try/catch로 감싸고, 실패 시 토스트 표시, 복원 실패 시 빈 상태로 초기화
4. **Toast 컴포넌트** → `components/Toast.tsx` + `lib/ToastContext.tsx` 추가. 어디서든 `showToast('메시지')` 호출 가능
5. **Sidebar.tsx 제거** → `page.tsx`에 `<aside>` 영역으로 직접 배치. 파일 수 감소
6. **`distance` 파생값** → Route 인터페이스에서 `distance` 필드 제거, `useMemo`로 waypoints에서 계산
7. **GPX import UX** → import 후 fitBounds로 지도 이동 + 가져온 루트를 활성으로 설정
8. **NCP 도메인 정책** → localhost, Vercel 프리뷰(*.vercel.app), 프로덕션 도메인 모두 NCP 콘솔에 등록 필요
9. **대량 import 경고** → 1000개 초과 웨이포인트 import 시 토스트 경고

  name: string;
