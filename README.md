# fieldNote

네이버 지도 위에서 경로를 그리고 GPX 파일로 내보내기/가져오기하는 웹 도구.

## 현재 상황

- **단계:** 디자인 단계 (구현 전)
- **기술 스택:** Next.js + 네이버 지도 API v3 (NCP)
- **배포:** Vercel (정적 호스팅, 서버 불필요)

## 핵심 기능 (예정)

- 지도 클릭으로 경로 그리기
- 여러 경로 색상별 구분 관리
- 총 거리 / 예상 이동 시간 표시
- GPX 파일 내보내기 / 가져오기
